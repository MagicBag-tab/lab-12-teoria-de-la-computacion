# Laboratorio 12 - Teoría de la Computación

Implementación en JavaScript con Node.js de los problemas 2, 3 y 4.

## Problemas

- **Problema 2:** ordenar una lista de diccionarios por una clave.
- **Problema 3:** obtener la transpuesta de una matriz rectangular.
- **Problema 4:** eliminar de una lista los elementos indicados.

## Ejecución

No se necesitan dependencias externas. Desde la raíz del proyecto, ejecuta:

```bash
node Problema_2/Problema_2.js
node Problema_3/Problema_3.js
node Problema_4/Problema_4.js
```
